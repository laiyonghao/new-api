# `1tok` 使用指南

## 前言

[1tok](https://1tok.xhh.club)，小红花技术领袖俱乐部旗下 AI 服务平台。聚合全球顶尖大模型， 为中小微企业提供稳定、安全、高性价比的一站式 API 接入。

## 注册登陆

可以自行注册，需要验证邮箱。

登陆后，进入[控制台](https://1tok.xhh.club/console)，可在 `操练场`体验不同的模型，默认的 `default`分组下，`gpt-5.3-codex`、`gpt-5.4`、`gpt-5.5`可以用，其它模型详见下文 `切换令牌的分组`。

## 充值与计费

`1tok` 是针对中小微企业用户的，所以没有开通线上充值的功能。小额可以加客服美宝的微信：`ai1tok`，通过转账让她代充。大额使用支付宝或者对公转账，可以开发票，详询美宝。

充值时，我们采用人民币美元 `1:1`的汇率，即充值 `1`人民币，账户余额就多 `1`美元。

后续的消费，均以美元计价。即按实际汇率 `7.3`计算，相当于按 `1.35`折计费。所以 `1tok`提供的模型服会有一个倍率参数，以调整实际价格。详见下方 `切换令牌的分组`。

| 序号 | 倍率 | 折扣     |
| ---- | ---- | -------- |
| 1    | 0.5x | 约0.7折  |
| 2    | 1x   | 约1.35折 |
| 3    | 1.5x | 约2折    |
| 4    | 2x   | 约2.7折  |
| 5    | 2.5x | 约3.4折  |
| 6    | 4.5x | 约6折    |

## 使用

连接点/BaseURL：`https://1tok.xhh.club`，通常不需要加 `/v1`（生成图片除外）
令牌/密钥/Key：在 `令牌管理`功能下生成和管理，点击 `密钥`字段值旁边的复制图标，下拉菜单选择 `复制密钥`即可粘贴到应用（如`Claude Code`）中。

## 切换令牌的分组

在 `令牌管理`功能，每一条记录右侧的 `编辑`按钮点开后可以修改分组。分组对应不同的模型和计费规则。下面阐述不同分组。

### `default` 和 `gpt-1x`

`default`是默认分组，可以调用 `gpt-5.3-codex`、`gpt-5.4`、`gpt-5.5`等模型。它也是 `gpt-1x`的别名，所以令牌可以选择 `gpt-1x` 分组来调用这些模型。

> 其中的 `1x`后缀表示它的计费规则是和刊例价格一样（原价）。`*x`后缀的意思是刊例价格的多少倍，如 `0.5x`表示刊例价格的一半。

### `gpt-0.5x`

可以调用 `gpt-5.3-codex`、`gpt-5.4`、`gpt-5.5`等模型，它的计费规则是刊例价格一半。

### `claude-1x`、`claude-1.5x`、`claude-1.5x-cache`、`claude-2x`

均可调用 `claude-haiku-4-5-20251001`、`claude-opus-4-6`、`claude-opus-4-7`、`claude-sonnet-4-6`等模型。

`claude-1x`、`claude-1.5x` 使用 `kiro`订阅逆向。`claude-1.5x-cache`在 `claude-1.5x`的基础上，提供了缓存支持，会比较省钱（但我实践下来不一定）。`claude-2x`是 `kiro`和 `Claude Code`订阅逆向混用，相当于好的里渗了一些不那么好的（有一段时间我体验是这个反而最省钱，但这句话不是承诺）。

具体用哪个令牌更好，可能需要你根据你的用途进行实践。

### `gemini-2.5x`

这个分组可以调用 `gemini-3.1-pro` 模型。

### 生图

> **重要：** 操练场不能生图，加客服美宝的微信：`ai1tok`，她会给你发一个`Python`示例脚本（也可用以测试）。

`1tok`也支持调用 `gpt-image-2`模型生图，信息分组是 `default`，但要注意，调用生图时，`BASE URL` 要配置为 `https://1tok.xhh.club/v1`，也就是后面必须加上 `/v1`，跟调用生文模型**不同**。

`default`分组里的`gpt-image-2-simple`俗称小白生图，只需要一点信息就可以生成精美图片。如提示词为“雷军直播间带货1tok品牌AI中转站，网址1tok.xhh.club”即可生成雷军带货形象。相对地，使用`gpt-image-2`模型时，同样的提示词，只会生成一个男性带货形象（缺乏雷军的真实信息）。

生图的计费是按次的：
| 序号 | 模型 | 费用     |
| ---- | ---- | -------- |
| 1    | gpt-image-2 | \$0.10  |
| 2    | gpt-image-2-simple   | \$0.15 |

**提醒：**
1. `size`参数可能会被上游忽略，不一定能够真实执行。
2. 接口有时候返回`base64`编码的图片，有时候返回 OSS 网址，具体处理可能需要编程解决，加客服美宝的微信：`ai1tok`，她会给你发一个`Python`示例脚本（也可用以测试）。
3. 操练场不能生图，加客服美宝的微信：`ai1tok`，她会给你发一个`Python`示例脚本（也可用以测试）。
